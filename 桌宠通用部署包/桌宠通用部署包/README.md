# 桌面宠物 · 通用部署包

双击 **`启动桌宠.bat`** 就能跑起来：第一次运行会自动建虚拟环境、自动装依赖（几分钟），之后每次启动只要一两秒。
本文件是**从零部署的完整步骤**；功能详解、实测数据、踩坑记录见同目录的 **`项目文档.md`**。

---

## 0. 先说清楚：这个包里有什么、没有什么

**有**：程序本体（全部 .py）、启动脚本、一个**示例角色**（纯几何图形画的占位素材，不含任何第三方图片）、
示例人设、配置模板、中文界面、两份文档。

**没有（重要）**：

| 没有 | 说明 |
| --- | --- |
| **任何 API Key** | 包里所有 `api_key` 字段都是空的。Key 只存在于**你自己电脑**上首次运行后生成的 `config.json` |
| **任何对话记录 / 记忆库** | 没有 `memory.db`。你和角色的聊天只存在你自己机器上 |
| **任何个人路径** | 没有作者的目录、中转站域名、录音文件名 |
| **任何私人素材** | 角色是现画的占位图；想换成自己的素材看第 9 步 |
| **运行环境** | 没有 `.venv`（体积大、和机器绑定）。第 3 步会自动建 |

> 唯一的"联网"行为都是**你配置之后**才发生的：对话 API、语音合成、屏幕理解、知识库联网。
> 什么都没配的情况下它也能跑——只是角色不会说话（Provider 默认 `compatible` 且 Key 为空，会回一句接口错误提示）。

## 1. 系统要求

| 项 | 要求 | 备注 |
| --- | --- | --- |
| 系统 | Windows 10 / 11（64 位） | Win7 没测过；PySide6 新版已不支持 |
| **Python** | **3.9 ~ 3.12，必须 64 位** | 作者在 3.9.13 上实测；3.13 没测过。32 位 Python 装不了 PySide6 |
| 磁盘 | 约 1.2 GB | 主要是 `PySide6`（约 700 MB）和 `.venv` |
| 内存 | 4 GB 以上 | 桌宠本身很轻；本地语音合成（可选）才吃内存 |
| 网络 | 配置 API 时需要 | 只挂着桌宠不配任何 Key 也能运行，不联网 |
| 可选硬件 | 麦克风 / 音箱 | 语音输入、朗读才需要 |

## 2. 部署步骤

### 第 1 步：解压

解压到一个**你自己的目录**，例如 `D:\DesktopPet\`。解压后应该能看到 `启动桌宠.bat` 和一堆 `.py`。

- 建议放在**本地盘**（`D:\`、`C:\Users\你\`）。
- **不要**放进 OneDrive / 坚果云等同步目录：同步程序会锁住 `.venv` 里的文件，导致启动或安装失败。
- 路径里可以有中文和空格（作者的项目目录就是中文名，实测没问题）；但别太深，Windows 有 260 字符路径限制。

### 第 2 步：安装 Python（已经装好可跳过）

1. 打开 <https://www.python.org/downloads/windows/>，下载 **3.9~3.12** 的 `Windows installer (64-bit)`。
2. 安装时**务必勾选最下面的** `Add python.exe to PATH`（漏了这步启动器可能找不到它）。
3. 验证：按 `Win+R` → 输入 `cmd` → 回车 → 输入 `python -V`，应显示 `Python 3.x.x`。

> **Microsoft Store 里的 python 不算数**：那是个跳转占位程序，创建虚拟环境会直接失败。
> 启动器会自动跳过它去找真正的 Python；如果你只装了 Store 版，请按上面重新装一次官方版。
>
> 已经装了 **Anaconda** 也可以，启动器会自动探测（`py` 启动器 → PATH → 官方安装目录 → Anaconda）。

### 第 3 步：一键安装依赖

**双击 `启动桌宠.bat`**。它会自动：

1. 找到可用的 Python（版本不够会提示）；
2. 在项目目录里创建 `.venv` 虚拟环境（不污染系统 Python）；
3. 检查 `requirements.txt` 里的四个依赖（`PySide6` `qasync` `httpx` `openai`），缺了就装——
   先直连试，失败会自动换**清华镜像**重试；
4. 装完**再验一次**能不能 import（防止"装完仍然起不来"）；
5. 启动桌宠。

首次安装大约 **3~10 分钟**（看网速），窗口里会显示进度，**别关窗口**。

只想检查环境、不启动的话，在项目目录打开 cmd 执行：

```
启动桌宠.bat check
```

想看到完整的报错信息（排查用）：

```
调试桌宠.bat
```

### 第 4 步：确认桌宠出来了

桌宠会出现在桌面上（默认在右下角附近）。此时：

- **鼠标移动** → 它转头的方向跟着鼠标（示例角色有八个方向的帧）；
- **鼠标长时间不动** → 自动切到「待机」动作；
- **右键桌宠** → 菜单：**切换动作**、**切换表情**（有表情素材时才出现）、**调整大小**、**关闭桌宠**；
- **按住 Ctrl 滚轮** → 缩放桌宠大小（40%~300%，每次 5%）；
- **双击** → 聊天输入窗（Enter 发送，Shift+Enter 换行）；
- **按住左键拖动** → 把桌宠挪到别处。

工作台是设置中心：**双击 `启动工作台.bat`**（工作台里本来也带着桌宠）。工作台里还有：
「桌宠大小」滑块、「视线灵敏度」滑块、动作/方向/帧间隔、待机动作、表情、语音、API、知识库等全部设置。

### 第 5 步：填对话 API（不填就不会真的聊天）

工作台右上角 **⚙ → API 配置**，按服务商给的信息填：

| 字段 | 怎么填 |
| --- | --- |
| **Provider** | 第三方中转站、OpenAI 官方、DeepSeek 等 OpenAI 兼容接口 → 选 `compatible`；本地 Ollama → 选 `ollama` |
| **模型** | 服务商文档里给的模型名，例如 `gpt-4o-mini`、`deepseek-chat`（**不同服务商名字不通用**） |
| **API Key** | 你的 Key |
| **API 地址** | 形如 `https://xxx.example.com`（**别漏 https://**）。Ollama 本地是 `http://localhost:11434/api/chat` |
| **最大回复 token** | 桌宠回复很短，`120~500` 就够；推理模型（思维链）要给 2000 以上 |

填完点 **「测试连接」**（会真发一句）→ 通了再点 **「保存」**。
「加载模型」按钮可以拉取该接口的模型列表，省得手打模型名。

> **可以存多套接口**：这块上方有「已保存的接口」——「增加」把当前填写存成一档，
> 之后在下拉里选中再点「保存」就能整套切换（比如"中转站"和"官方直连"两档）。
> 「保存」时如果发现这套还没存进任何档位，它会主动问你要不要存下来。

### 第 6 步（可选）：让角色说话（文字转语音）

工作台 **⚙ → 语音合成设置**。三种方式任选：

| 方式 | 需要什么 | 特点 |
| --- | --- | --- |
| **云端 · Qwen-TTS** | 阿里云百炼（DashScope）API Key | 音色多、快、按量计费；可用录音**复刻音色**（上传本地录音即可） |
| **云端 · Qwen-Audio-TTS** | 同上（Key 可复用） | **语气控制最强**，可复刻音色；音色与上面那套**不通用** |
| **本地 · GPT-SoVITS** | 自己装一个 GPT-SoVITS 整合包 | 免费离线，CPU 推理慢（按句合成、边合成边播） |

关键几步：

1. 勾上「启用」；
2. 选合成方式 → 填 Key / 音色（或参考音频）；
3. 在「**试听**」框里打一句、点「用当前音色试听」——能听到就成功了；
4. 想让它"有语气"：在「语气标注提示词」那块写一段（默认已内置），角色就会按上下文给每句话标语气，
   例如同一句"这样的结局，真是让人遗憾"在得意时读成"小声不甘"、失落时读成"低落"。

> 本地 GPT-SoVITS 走的是 `http://127.0.0.1:9880`，得先把那个服务跑起来——见下面这节。

#### 本地语音合成（免费离线）：双击 `启动本地语音服务.bat`

桌宠自带这条路的完整实现（**不用装任何额外的 Python 包**），但要先把 GPT-SoVITS 的服务跑起来。
包里给了两个双击即用的脚本：

| 双击 | 作用 |
| --- | --- |
| **`启动本地语音服务.bat`** | 启动整合包里的 `api_v2.py`。**会弹出一个控制台窗口显示加载进度**——几十秒到几分钟，那个窗口是唯一能看到「加载到哪一步、报什么错」的地方，**别关它** |
| **`检查本地语音服务.bat`** | 体检四件事：配置 / 整合包目录 / 服务端口 / 参考音频（要 3~10 秒）。不联网、不花钱 |

命令行也能用（`action` 可以省，默认是 `check`）：

```
.venv\Scripts\python.exe 本地语音服务.py check    # 体检
.venv\Scripts\python.exe 本地语音服务.py start    # 启动服务（新控制台窗口显示进度）
.venv\Scripts\python.exe 本地语音服务.py test     # 服务起来后，真合成一句，存成 本地语音测试.wav
.venv\Scripts\python.exe 本地语音服务.py ref      # 检查并整理参考音频（3~10 秒规则）
.venv\Scripts\python.exe 本地语音服务.py stop     # 停止服务（等于调 /control?command=exit）
```

**四步跑通：**

1. **装整合包**：从 GPT-SoVITS 官方仓库/整合包页面下载，解压到任意目录。目录里要同时有
   `api_v2.py` 和 `runtime\python.exe`（脚本就靠这两个文件认路）。
2. **告诉桌宠它在哪**：工作台 → 语音合成设置 → 本地 → 「整合包目录」填进去。
   不想手填也行——`本地语音服务.py start --home "D:\GPT-SoVITS"` 会自动找到并写回 `config.json`；
   常见位置（`D:\GPT-SoVITS`、桌面、下载目录等）它也会自己找一遍。
3. **双击 `启动本地语音服务.bat`**，等控制台里出现监听信息；再**双击 `检查本地语音服务.bat`** 确认端口通了。
4. **桌宠里切过去**：工作台 → 语音合成设置 → 合成方式选「**本地 · GPT-SoVITS**」→ 选参考音频 →
   点「**检测**」→ 点「**用当前音色试听**」。
   想先单独验证整条链路：跑 `本地语音服务.py test`，成功会打印「x 秒出 y 秒音频」并存出 `本地语音测试.wav`。

**要点和坑（都是实测踩过的）：**

- **参考音频要 3~10 秒**（干净单人声）。不在这个范围也不用自己剪——桌宠合成时会自动削首尾静音、
  截一段写成临时文件交给接口，**你的原文件一个字节都不动**。想单独看这一步：`本地语音服务.py ref`。
- **参考音频是「服务端本机路径」**：api_v2 没有开放上传接口，所以文件得在本机、给绝对路径即可。
- **参考文本**（选填）填了音色更准，但**必须和音频一字不差**；参考音频是日文原声时，「参考语言」要选 `ja`，
  「合成语言」按台词选 `zh`。
- **CPU 推理慢**：一句十几秒很正常（本机实测：11 字约 5 秒出 2.6 秒音频），所以桌宠是**按句合成、边合成边播**，
  第一句先出声。
- **换自己训的权重**：本地页填好 GPT / SoVITS 权重路径 → 点「加载模型（应用权重）」。
- **服务起不来就看那个控制台窗口**。最常见的是整合包里依赖冲突，在整合包目录执行一次通常就能修好：
  `runtime\python.exe -m pip install "librosa==0.9.2" "numba==0.56.4" "numpy==1.23.4"`
- 不想每次手动启动：把 `go-api.bat`（整合包自带的）放进开机启动项，或给这个 bat 建个快捷方式。

### 第 7 步（可选）：语音输入（对着麦克风说话）

工作台 **⚙ → 语音输入设置**：

| 方式 | 需要装什么 |
| --- | --- |
| **vosk（离线，推荐）** | 1) 装库：项目目录执行 `.venv\Scripts\python.exe -m pip install vosk`；2) 下模型：<https://alphacephei.com/vosk/models> 找 **`vosk-model-small-cn-0.22`**（约 42 MB），解压后放进项目目录的 `models\vosk-model-small-cn-0.22\`（里面应该直接是 `am`、`conf`、`graph` 等文件夹） |
| **在线识别** | 一个支持语音识别的 OpenAI 兼容接口（例如 SiliconFlow 的 `FunAudioLLM/SenseVoiceSmall`）+ 它的 Key |

装好后点「检测语音输入」确认。聊天窗上的「语音」按钮：点一下开始录，再点一下结束并识别，识别结果会先填进输入框（让你看一眼再发）。

### 第 8 步（可选）：屏幕理解（让角色看一眼你的屏幕）

工作台 **⚙ → 屏幕理解设置**：填一个**支持看图的视觉模型**（可以和对话 API 不是同一条），
选"整屏 / 指定区域 / 锁定某个窗口"，再设节奏（多久看一眼、你沉默多久才看）。默认关闭，隐私优先。
截图只在内存里传给模型、**不落盘**，识别结果也**不写进对话记录**。

### 第 9 步（可选）：换成你自己的角色素材

把素材按这个结构放，重启桌宠即可（工作台里也能建动作、导入帧，不用手改目录）：

```
assets/characters/你的角色名/
├── motions/
│   ├── idle/            ← 跟随鼠标转头用的「八方向」动作
│   │   ├── N/  000.png 001.png …
│   │   ├── NE/  E/  SE/  S/  SW/  W/  NW/
│   ├── 待机/            ← 无方向动作：PNG 直接放在动作目录下（长时间不动时轮播）
│   │   ├── 000.png 001.png …
│   └── durations.json   ← 可选：给每帧单独设时长
├── expressions/         ← 可选：表情（目录名就是表情名，目录里直接放 PNG）
│   └── 开心/ 000.png …
└── prompts/persona.json ← 可选：这个角色专用的人设（不写就用项目根的 prompts/persona.json）
```

- 帧图建议 160×160 ~ 512×512 的 **PNG（带透明通道）**，桌宠窗口是 256×256，会自动缩放。
- 八方向子目录名必须是 `N NE E SE S SW W NW`（缺哪个方向会用最近的方向顶替）。
- 想换个角色名、加多个角色：在 `assets/characters/` 下建多个目录，工作台里能切换。

## 4. 怎么确认部署成功

按顺序三步，全过就说明环境没问题：

1. **环境自检**：项目目录执行 `启动桌宠.bat check`
   → 看到 `[OK] 自检通过：虚拟环境与依赖都正常。`
2. **功能自检**（离线、不联网、不花钱）：项目目录执行
   ```
   .venv\Scripts\python.exe 语气自测.py
   ```
   → 看到 `全部通过`（它会检查语气标记解析、两套语音接口的请求体、复刻参数、配置分档等）。
3. **真启动一次**：双击 `启动桌宠.bat`，桌宠出现；右键 → 「调整大小」能拉开，双击能唤起聊天窗。
4. **（可选）本地语音自检**：双击 `检查本地语音服务.bat`
   → 它会直说「整合包找到了没、服务在不在跑、参考音频合不合格」。服务和参考音频都就绪后，
   再执行 `.venv\Scripts\python.exe 本地语音服务.py test`，能存出 `本地语音测试.wav` 就说明
   **本地语音合成整条链路通了**（不花钱，纯本地）。

## 5. 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 窗口一闪就没了 / 提示找不到 Python | 没装 Python，或没勾 `Add python.exe to PATH`。重装 Python（勾上那个选项），或用 Anaconda。用 `调试桌宠.bat` 能看到具体报错 |
| `[错误] 没有找到可用的 Python（需要 3.9 或更高版本）` | 只装了 Microsoft Store 版 python（占位程序），或版本低于 3.9，或装的是 32 位 |
| pip 安装很慢 / 超时 | 启动器已自动回退清华镜像；仍失败就手动执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `No module named PySide6` | `.venv` 没建好或依赖没装完。删掉 `.venv` 目录再双击 `启动桌宠.bat` 重来 |
| 桌宠起来了但聊天回「暂时无法连接…」 | Key / 地址 / 模型名不对，或余额不足。看气泡里的错误码：`401` 是 Key，`404` 多为模型名或地址，`403` 可能是欠费/额度。完整的报错在 `app.log` 里 |
| 模型名报 `does not exist` | 模型名和服务商不匹配（换服务商要换模型名，例如中转站的 `gpt-4o-mini` 在别处可能不存在）。用对话框里的「加载模型」拉列表 |
| 双击没反应 / 没看到桌宠 | 桌宠可能在屏幕边缘外。看 `app.log` 里的启动记录；或用工作台里的桌宠位置选项复位 |
| 杀毒软件报毒 / 拦下 `.bat` | 批处理会创建虚拟环境、执行 pip，属于正常行为；加入信任即可。也可以不用 `.bat`，手动执行 `python -m venv .venv` → `pip install -r requirements.txt` → `.venv\Scripts\pythonw.exe main.py pet` |
| 没有声音 | ① 聊天窗右下「静音」有没有勾上；② 语音合成设置里「启用」有没有勾；③ 先用「试听」确认能出声；④ 系统音量/输出设备 |
| 语音输入没反应 | 第 7 步：装了 `vosk` 库 + 模型目录放对位置了吗（`检测语音输入` 会直说缺什么） |
| 路径里有 OneDrive / 网盘 | 同步程序会锁文件，务必换到本地目录 |
| 想恢复出厂配置 | 删掉 `config.json`（和 `memory*.db` 会一起失去聊天记忆），重启即重新生成 |

## 6. 更新 / 卸载

- **更新**：把新版本的 `.py`、`.bat`、`项目文档.md` 覆盖进来即可；`config.json`、`memory.db`、`assets/`、`prompts/` 是你自己的数据，**不要覆盖**（新版本如果在 `config.example.json` 里加了新字段，照着补进 `config.json` 就行）。
- **卸载**：直接删掉整个目录。它不写注册表、不装系统服务、不在别处留文件（`%TEMP%` 下会留几个语音合成的临时 wav，重启会清）。

---

## 7. 隐私与安全

- 包里**没有任何凭据**；你填的 Key 存在本项目目录的 `config.json` 里（**明文**，和大多数桌宠类的本地配置一样）。
  介意的话：别把整个目录分享给别人，或分享前删掉 `config.json`。
- `memory.db` 是你和角色的聊天记录与"记忆"，也只在本机。
- `app.log` 是运行日志，**可能包含接口报错原文和少量对话内容**；分享日志前留意一下。
- 屏幕理解默认**关闭**；开了之后截图只在内存里传给视觉模型，不落盘、不写进对话记录。
- 只有你配置过的那些服务（对话/语音/视觉/搜索）会收到数据。
